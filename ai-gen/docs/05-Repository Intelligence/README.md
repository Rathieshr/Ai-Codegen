# Repository Intelligence

Repository Intelligence turns registered Git or Azure DevOps repositories into versioned engineering evidence.

## Lifecycle

`Register -> Synchronize -> Snapshot -> Parse -> Graph -> Rank -> Monitor`

## Capabilities

- Repository registration and status.
- Full and incremental synchronization.
- Versioned metadata snapshots and comparison.
- Multi-language symbol parsing.
- Engineering Graph construction and refresh.
- Work-item-aware file ranking.
- Repository Context Capsule inputs.
- Event-driven agent operation and monitoring.

Use **Repository Synchronization** in product language. `scan` remains a compatibility API/internal term until a versioned migration is complete.
