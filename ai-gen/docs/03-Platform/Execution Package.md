# Execution Package

The Execution Package is the canonical, deterministic engineering execution contract. It contains planning context, repository evidence, approved knowledge and memory references, implementation boundaries, acceptance mapping, validation guidance, QA guidance, readiness, versions, and diagnostics.

It is not a prompt and does not require an AI provider. Prompt Intelligence, Validation, QA, Engineering Memory Capture, agents, and IDE integrations consume it.
