# Context Capsule

The Context Capsule is the immutable output of Context Intelligence. It contains selected evidence, rejected evidence, provenance, source versions, freshness, confidence, token estimates, boundaries, and correlation identity.

The Execution Package Builder is its primary consumer. Downstream services do not query the capsule's source systems independently.

See [Context Intelligence](../01-Architecture/Context%20Intelligence.md) and the historical [Context Capsule specification](../specifications/CONTEXT_CAPSULE_SPEC.md).
