# Engineering Command Center

The Portal presents the HEI lifecycle as a guided Engineering Command Center.

Primary areas:

- Current project, repository, knowledge, and provider health.
- Current artifact and lifecycle stage.
- One recommended next action with blockers.
- Planning, Execution, QA and Release, and Engineering Memory workspaces.
- Advanced governance, agents, skills, administration, and diagnostics.

The Portal does not create parallel intelligence logic. It renders backend lifecycle, artifact, trace, and policy contracts.
