# Testing

HEI testing covers:

- Unit tests for intelligence, artifacts, policies, and services.
- Contract tests for Context Capsules, Execution Packages, and consumers.
- Repository-mode safety tests.
- Token-budget and provider-response tests.
- Lifecycle and approval tests.
- End-to-end platform hardening scenarios.
- API, extension build, and integration validation.

See [Platform Hardening](../testing/platform-hardening.md) for the Milestone 3.5 architecture, scenarios, quality gates, performance baseline, and CI command.

See [Prompt Intelligence Hardening](../testing/prompt-intelligence-hardening.md) for the Milestone 4.10 adapter, token, cache, routing, diagnostics, regression, and benchmark gates.
