# Command Center Navigation

Navigation remains role-aware and lazy-loaded.

| Workspace | Viewer | Contributor | Admin |
| --- | --- | --- | --- |
| Overview, Planning, Execution, Azure DevOps, Activity, Health, Memory | Yes | Yes | Yes |
| Approvals, Agents | No | Yes | Yes |
| Repository, Settings, Administration | No | No | Yes |

**Health** opens the production operational workspace. **Activity** opens the chronological engineering lifecycle. Detailed Health diagnostics are visible only to admins. Disabled and future navigation entries cannot be opened through the sidebar, workspace switcher, search, or command palette.
